# Горный массив на девять гексов — прототип v1

Текстурированный вариант с UV/PBR, упакованным исходником Blender и отдельной
сценой Godot находится в `textured_v1/README.md` и уже подключён к карте. Описание ниже относится
к сохранённому серому прототипу.

Единая гора с доминирующим пиком, боковым хребтом, отрогами, седловинами,
обрывистыми склонами и общими предгорьями. Форма сделана по направлению
третьего референса владельца. Материал нейтральный серый; текстур,
карт нормалей и отдельных снежных накладок нет. Борозды находятся в геометрии.

Этот серый вариант сохранён для сравнения формы. Игровая карта использует
текстурированный GLB из `textured_v1/`, с размещением по группам горных
клеток и отдельным шейдером контура и тумана.

## Открыть и посмотреть

- `source/mountain_massif_9hex_v1.blend` — редактируемый исходник, свет и камеры.
  Активная сцена `Mountain_Massif_9_Hex_Clay`; гора находится в `Massif_Export`.
  `Preview_Only` содержит служебные линии гексов и освещение. Линии скрыты
  в обычном виде; их можно включить для проверки масштаба.
- `models/mountain_massif_9hex_v1.glb` — один облегчённый меш с одним материалом.
  Камеры, свет, стандартный куб Blender и сетка гексов в экспорт не входят.
- `preview.tscn` — отдельная сцена просмотра в Godot: открыть и запустить F6.
- `previews/massif_front.png`, `massif_reverse.png` — рендеры исходника.
- `previews/massif_footprint.png` — вид сверху с разметкой девяти гексов.
- `previews/massif_game_mesh.png` — облегчённая геометрия в Blender.
- `previews/massif_godot.png` — именно экспортированный GLB в Godot Compatibility.
- `manifest.json` — размеры, контур и точное количество треугольников.

## Масштаб и контур

Радиус гекса 1. Начало координат соответствует центру клетки `(0, 0)`
на уровне основания. Габариты около 6,93 × 5,00 × 2,81 в Blender (Z вверх).
В Godot это 6,93 × 2,81 × 5,00 (Y вверх), низ на Y=0.
Поверхность сварена между гексами; внутренних стенок нет. Нижняя поверхность
замкнута и повторяет вогнутый внешний контур, не перекрывая соседние клетки.
Облегчение немного скругляет углы основания (до 0,02 от радиуса гекса);
точные габариты исходника и экспорта записаны в манифесте отдельно.

`footprint_axial` в манифесте задаёт клетки уже в координатах игровой сетки
Godot: X=√3·(q+r/2), Z=1,5·r. `footprint_blender_xy` сохраняет контур исходника:
экспорт glTF преобразует `(x,y,z)` Blender в `(x,z,-y)` Godot, поэтому
для клеток используется преобразование `(q,r) → (q+r,-r)`.

Исходник содержит 209 088 треугольников, бюджет отдельного экспорта — около
45 000. Godot дополнительно создаёт LOD. Одна связная замкнутая поверхность
проверяется в Blender после облегчения; импорт, отсутствие лишних мешей,
размеры, положение основания, материал без текстур и число треугольников —
скриптом Godot.

## Воспроизведение

Создание выполняется нативным Python API Blender. При этой работе MCP-сервер
не отвечал, поэтому использовался отдельный фоновый экземпляр Blender 4.5.3;
открытая пользовательская сцена не изменялась. Скрипт записывает только
файлы этого прототипа, при повторном запуске заменяет их.

```powershell
& 'C:/Program Files/Blender Foundation/Blender 4.5/blender.exe' --background --factory-startup --python-exit-code 1 --python tools/blender/build_mountain_massif.py
godot --headless --path . --editor --import
godot --headless --path . -s tools/check_mountain_massif.gd
godot --path . -s tools/check_mountain_massif.gd -- --preview
```
