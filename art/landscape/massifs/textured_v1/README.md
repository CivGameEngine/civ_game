# Текстурированный горный массив v1

Тот же массив на девять гексов, с UV-развёрткой и запечённым материалом.
Геометрия взята из готового серого GLB без повторного упрощения: 45 000
треугольников. Серый прототип в родительской папке сохранён.

Сгенерирована серо-коричневая скала с трещинами и минеральными вкраплениями.
В Blender материал сначала проецируется с трёх направлений, чтобы на крутых
стенах не было сильного растяжения. Маска снега зависит от высоты, наклона
и шума, поэтому снежные участки располагаются преимущественно на верхних
пологих поверхностях. Результат запечён в обычные UV-карты.

## Файлы

- `source/mountain_massif_9hex_textured_v1.blend` — открыть в Blender.
  Активная сцена `Mountain_Massif_Textured_v1`, видимый объект
  `mountain_massif_9hex_textured_v1`, развёртка `Massif_UV`.
  Все четыре изображения упакованы в файл, пути сделаны относительными.
  Исходная геометрия повышенной детализации сохранена скрытой как
  `HighPoly_Clay_Archive`. Пользовательская сцена `Scene` не изменялась.
- Материал `Massif_PBR_Baked_UV` используется моделью. Материал
  `Massif_Authoring_Triplanar_Snow` сохранён отдельно для изменения маски
  снега и повторного запекания; его можно выбрать в списке материалов.
- `models/mountain_massif_9hex_textured_v1.glb` — один меш, один PBR-материал,
  встроенные текстуры. Подходит для переноса в Godot без внешних зависимостей.
  Соседние `models/*.png` извлечены Godot из GLB при импорте, включая
  упакованный канал шероховатости; они также сохранены в репозитории.
- `preview.tscn` — открыть в Godot и запустить F6.
- `textures/rock_generated_albedo.png` — неизменённый результат `image_gen`,
  1254 × 1254; повторяется при проецировании на большую поверхность.
  Полный запрос и происхождение — `textures/PROMPT.md`.
- `textures/massif_albedo.png` — UV-атлас цвета 4096 × 4096, sRGB,
  без запечённого освещения и теней.
- `textures/massif_normal.png` — нормали 2048 × 2048, Non-Color.
  Микрорельеф получен из яркости сгенерированной скалы через Bump и запечён
  в касательное пространство; это художественная карта, не измеренный скан.
- `textures/massif_roughness.png` — шероховатость 2048 × 2048, Non-Color.
  При экспорте glTF она упаковывается в металлический/шероховатый канал.
- `previews/` — фронтальный, обратный, верхний ракурсы, крупный план и рендер
  GLB в Godot; `uv_layout.svg` показывает треугольники развёртки.
- `manifest.json` — контур, размеры и данные текстур.

Модель остаётся отдельным ассетом: на игровую карту она пока не подключена.
Для размещения целого массива на группе клеток ещё нужен отдельный этап.

## Воспроизведение через Blender MCP

Загрузить `tools/blender/texture_mountain_massif.py` через `importlib.util`
как модуль, затем вызвать последовательно:

```python
module.load_source_scene()
module.prepare()
module.author_material()
# На этом месте можно осмотреть авторский материал перед запеканием.
module.start_job()
```

Тяжёлая часть выполняется таймером Blender, чтобы вызов MCP сразу вернулся.
Состояние записывается в игнорируемый Git файл `source/job.json`.
Скрипт повторно записывает только текстурированный вариант, сохраняя серый
исходник. Сохранение выполняется как копия, не подменяя путь пользовательского
документа. Папка `source` исключена из импорта Godot через `.gdignore`.

```powershell
godot --headless --path . --editor --import
godot --headless --path . -s tools/check_mountain_massif.gd -- --textured
godot --path . -s tools/check_mountain_massif.gd -- --textured --preview
```

Проверены импорт GLB, один меш, размеры, положение основания, 45 000
треугольников, наличие трёх PBR-карт и допустимые UV-координаты.
Отдельно сохранена проверка серого прототипа без флага `--textured`.
